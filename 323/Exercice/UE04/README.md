# Starter UE04 : catalogue

Projet console C# .NET 8. Il compile tel quel.

## Mise en route

1. Copiez le dossier `_starter-UE04-catalogue` dans votre espace de travail.
2. Renommez la copie `M323-UE04-VotreNomUtilisateur`.
3. Ouvrez le dossier dans Visual Studio, ou lancez `dotnet run` depuis ce dossier.
4. La sortie attendue au premier lancement est : `12 voitures chargées.`

## Contenu

| Fichier | Rôle |
|---|---|
| `Voiture.cs` | le `record` du fil rouge, immuable. Ne pas modifier |
| `Donnees.cs` | les douze voitures. Ne pas modifier |
| `Exercices.cs` | exercices 1 et 2, zones `// A COMPLETER` |
| `Rapports.cs` | exercice 3, le tableau de bord du garage |
| `Program.cs` | le point d'entrée et vos appels |

LINQ est autorisé à partir de cette UE.

Valeurs de contrôle : total 303 400 CHF, 730 000 km, 4 essence, 3 diesel,
3 électriques, 2 hybrides. Prix moyen des électriques : 31 333,33 CHF.
