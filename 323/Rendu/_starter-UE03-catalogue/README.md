# Starter UE03 : catalogue

Projet console C# .NET 8. Il compile tel quel.

## Mise en route

1. Copiez le dossier `_starter-UE03-catalogue` dans votre espace de travail.
2. Renommez la copie `M323-UE03-VotreNomUtilisateur`.
3. Ouvrez le dossier dans Visual Studio, ou lancez `dotnet run` depuis ce dossier.
4. La sortie attendue au premier lancement est : `12 voitures chargées.`

## Contenu

| Fichier | Rôle |
|---|---|
| `Voiture.cs` | le `record` du fil rouge, immuable. Ne pas modifier |
| `Donnees.cs` | les douze voitures. Ne pas modifier |
| `Exercices.cs` | vos zones de travail, marquées `// A COMPLETER` |
| `Program.cs` | le point d'entrée et vos appels |

## Règles de l'UE03

Aucun opérateur LINQ. `Where`, `Select`, `Sum` et `Count()` sont interdits jusqu'à l'UE04.
Vous écrivez vos boucles.

Valeurs de contrôle du catalogue : total 303 400 CHF, 730 000 km, 4 essence, 3 diesel,
3 électriques, 2 hybrides.
